        Graph Gallery Help

        Datasets

        • MIMIC-III — Medical Information Mart for Intensive Care III; the primary dataset for both pipelines and all comparison experiments.
        • MIMIC-IV — Updated MIMIC with more recent data (EHR-Dataset-Processing pipeline only).
        • eICU — eICU Collaborative Research Database (EHR-Dataset-Processing pipeline only).
        • Cross — Pipeline comparison graphs that span both MIMIC_Extract and EHR-Dataset-Processing.

        Pipelines

        • MIMIC_Extract — Published Wang et al. 2020 pipeline, ported to Python 3.9 / Apptainer. Outputs 13 cohort scenario variants from a single Postgres MIMIC-III instance.
        • EHR-Dataset-Processing — In-house pipeline supporting MIMIC-III, MIMIC-IV, and eICU. Applies 12 sequential filters (7 per-vital outlier + 4 structural) then 5 aggregation methods; uses cuML RandomForest on GPU.
        • Comparison — Cross-pipeline notebook (pipeline_comparison.ipynb) comparing the two on a shared 27,295-stay MIMIC-III cohort with logistic regression / McNemar tests.

        Aggregation Methods

        Both pipelines support the same five methods for collapsing the 24-hour timeseries into a feature vector:

        • Mean — average value per vital across all hours
        • Median — median value per vital
        • Standard Deviation — spread of values per vital
        • Mean Deviation — mean absolute deviation from the mean
        • Maximum Deviation — maximum absolute deviation

        Labels

        • icu / icu_los — ICU length of stay > 3 days (binary)
        • mortality — in-hospital mortality (binary)

        Plot Types

        • Filter Impact Bar — deviation from raw (no-filter) baseline for a given metric; green = improvement, red = degradation.
        • McNemar Significance — −log₁₀(p-value) for each filter/scenario vs baseline; orange bars cross the p=0.05 threshold line.
        • Centroid Shift — per-vital deviation of class centroid after filtering; shows which vitals are affected most.
        • Centroid Distribution — density violin plots for raw vs filtered positive/negative groups per vital.
        • Lens Plot — aggregation method × hour heatmap for a single vital in the MIMIC_Extract baseline cohort.
        • PCA Centroid Shift — 2-D PCA scatter showing baseline (red star) vs variant scenario centroids with connector lines.
        • Error-Bar — mean ± 1 std dev + median across scenarios for a single vital.

        EHR-Dataset-Processing Filters

        The EHR pipeline applies preprocessing filters at three levels to the 24-hour × 7-vital timeseries matrices before training the classifier.

        Value-level — remove individual out-of-range readings for one vital sign before averaging each cell:

        • heart rate — drops readings outside 1–600 bpm
        • systolic blood pressure — drops readings outside 1–400 mmHg
        • diastolic blood pressure — drops readings outside 1–300 mmHg
        • mean blood pressure — drops readings outside 1–300 mmHg
        • respiration rate — drops readings outside 1–70 breaths/min
        • temperature — drops readings outside 21–60 °C
        • oxygen saturation — drops readings outside 1–100%
        • all vitals — applies all 7 per-vital outlier filters simultaneously

        Feature-level — modify cells after the timeseries is flattened to a 2-D matrix:

        • fill missing data — KNN imputation (k=3) fills missing hourly values column-by-column; only applied when at least 2 valid readings exist in that vital's column

        Sample-level — discard entire patient records that fail a quality threshold:

        • long missing segment — removes records where any single vital column has ≥10 consecutive missing/zero cells (i.e., a long stretch of missing data for one vital sign). Note: name is ambiguous — see "long gap" below.
        • long gap — removes records with ≥2 completely empty consecutive hour rows (i.e., all 7 vitals absent for 2+ hours in a row). Note: name is ambiguous; this is a row-level blackout, distinct from "long missing segment" which is column-level.
        • high invalid data — removes records where more than 10% of all cell values are invalid or missing

        MIMIC_Extract Cohort Scenarios

        The MIMIC_Extract pipeline does not apply preprocessing filters; instead it produces 13 distinct cohorts by varying cohort-selection parameters at extraction time. Each scenario is an independent dataset with different patient inclusion criteria.

        Cohort-selection parameters:

        • min_age / max_age — admission age bounds (years); default is 15–999 (no upper limit)
        • min_duration / max_duration — ICU stay length bounds (hours); default is 12–240 hours
        • min_percent — drops any vital/lab column with more than (100 − min_percent)% missing values across the cohort; default 0 (keep all columns)
        • pop_size — caps the cohort to the first N ICU stays; 0 = no cap (full dataset)

        The 13 scenarios:

        • pop5000 — 5,000-stay subset of the full cohort (pop_size=5000); useful as a fast baseline
        • min48hr — ICU stays of 48–240 hours only; excludes short admissions
        • min18age — adult patients only (min_age=18)
        • minperc5 — stricter data quality: drops any vital/lab column with >95% missing values (min_percent=5)
        • age35_range5 — patients aged 33–37 (target age 35, ±2 years)
        • age35_range10 — patients aged 30–40 (target age 35, ±5 years)
        • age35_range15 — patients aged 28–42 (target age 35, ±7 years)
        • age45_range5 — patients aged 43–47 (target age 45, ±2 years)
        • age45_range10 — patients aged 40–50 (target age 45, ±5 years)
        • age45_range15 — patients aged 38–52 (target age 45, ±7 years)
        • age55_range5 — patients aged 53–57 (target age 55, ±2 years)
        • age55_range10 — patients aged 50–60 (target age 55, ±5 years)
        • age55_range15 — patients aged 48–62 (target age 55, ±7 years)

        The three age-targeted groups (35 / 45 / 55) each come in three window widths (range5/10/15), allowing comparison of how cohort age-range breadth affects model behaviour.
